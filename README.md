# Detector de notas

App web (instalable en el celular) que detecta las notas musicales de una melodía.

- Sube un audio, grábalo con el micrófono o comparte una canción desde Spotify.
- Muestra las notas en un rollo de piano, con su duración y la tonalidad probable.
- Crea un instrumental quitando la voz (canciones en estéreo).

Ábrela en https://octa09.github.io/musical-detector/ y agrégala a la pantalla de inicio.
